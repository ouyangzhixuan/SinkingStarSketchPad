SinkingStarSketchPad 3.4.6 — Minimal manual installation

NEW INSTALL
Save and completely exit the game. Locate the folder containing sinking_star.exe.
If no other ReShade/graphics proxy is installed, copy the three files INSIDE game_files:
dxgi.dll, SinkingStarSketch.addon64, ReShade.ini. No installer script is needed.

UPGRADE
Exit the game and back up the old add-on/configuration. Replace only SinkingStarSketch.addon64.
Keep your existing dxgi.dll, ReShade.ini and SinkingStarSketch-data (drafts/preferences).
Ensure [INPUT] InputProcessing=1 in ReShade.ini.
To remove an old bundled font, first clear [STYLE] Font to Font= in ReShade.ini,
then remove NotoSansCJKsc-Regular.otf from SinkingStarSketch-assets. Do not delete Windows fonts.

FONTS
No font files are bundled. ReShade chooses a system or built-in font based on its own UI language.
If Chinese text shows missing glyphs, press Home, open ReShade settings and choose an installed
Chinese-capable global font, e.g. C:\Windows\Fonts\msyh.ttc if present. Restart if necessary.
An English Windows installation may need a Chinese font installed separately; English UI works
with the built-in font. The mod language menu does not change ReShade's language or font.

CONTROLS
E drawing; G cursor; B marks; T free camera. WASD pans, Q/Z changes height,
right drag rotates, wheel zooms. T/Esc leaves camera controls and keeps the view by default.
Disable Keep view on exit for automatic restoration, or click Restore game view.
Default speed is 5; existing saved preferences remain. The camera is experimental and original
scene culling may not follow large changes.

UNINSTALL
Exit the game and move SinkingStarSketch.addon64 out of the game folder. Keep
SinkingStarSketch-data for drafts. Remove dxgi.dll/ReShade.ini only if no other mod shares them.
