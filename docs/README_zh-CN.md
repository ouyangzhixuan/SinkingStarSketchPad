# SinkingStarSketchPad 3.2

《沉星之序》的游戏内绘图与路线标记工具。提供星芒鼠标光标、画笔、几何图形、文字、三页草稿和自动吸附格心的路径。通过原生 64 位 ReShade 插件绘制到 DirectX 12 游戏画面。

**当前为 Beta。** 已验证真实游戏上传数据、自动格子推导、相机投影和中英文界面，尚未在所有实际关卡中完成视觉对齐验证。请先检查格心预览。

## 安装和升级

1. 保存进度，正常退出游戏，并完整解压发布包。
2. 双击 **安装Mod.cmd**，工具会尝试识别 Steam 游戏库。
3. 没有识别到唯一安装目录时，将正确的 **sinking_star.exe** 拖到 **安装Mod.cmd** 上。
4. 启动游戏，按 **E** 打开工具栏。

发布包包含经过验证的 ReShade 6.8.0 完整插件运行库、插件本体、配置和开放许可的 Noto 中英文字体。无需额外下载运行库。支持从已知 v2.1、v3.0、v3.1 升级，保留原配置、草稿、导出和语言设置，并备份旧插件及升级前草稿。

遇到其他 Mod 的 `dxgi.dll`、不同插件、字体或配置时，脚本会在写入前停止。已有 ReShade 的用户请先备份，阅读英文说明中的 Existing ReShade installations；不要强行覆盖已有图形插件。本版只验证了附带的 6.8.0 运行库。

安装工具会在解压目录创建本地 `installation.json`，其中记录游戏路径。分享时请上传原始发布 ZIP，不要重新打包已经安装过的解压目录。

## 中英文切换

工具栏 **Language / 语言** 菜单提供 System、English 和简体中文。System 在中文 Windows 界面语言下显示中文，其余使用英文。选择立即生效，重启后保留。

设置文件为游戏目录中的 `SinkingStarSketch-data/settings.ini`：

```ini
[Interface]
Language=zh-CN
```

还可填写 `en` 或 `auto`。切换的是 Mod 界面和通知，不会翻译你输入的文字或游戏本身。ReShade 的 Home 面板语言单独管理。

## 常用操作

| 操作 | 按键 |
| --- | --- |
| 进入/退出绘图 | E |
| 指针显隐 / 草稿显隐 | G / B |
| 取消笔画或文字；否则返回游戏 | Esc |
| 画笔 / 直线 / 箭头 | P / L / A |
| 矩形 / 椭圆 / 文字 | R / O / T |
| 整笔橡皮 / 格子路径 | K / H |
| 绘图 | 按住左键拖动 |
| 五种笔色 | 1–5 |
| 45 度直线、正方形或正圆约束 | 按住 Shift |
| 撤销 / 重做 | 右键或 Ctrl+Z / Ctrl+Y |
| 三页草稿 | Ctrl+1 / Ctrl+2 / Ctrl+3 |
| 保存 / 清空本页（可撤销） | Ctrl+S / Ctrl+Shift+Delete |
| 完成文字 | Ctrl+Enter |

E/G/B 只在不按 Ctrl/Shift/Alt 且没有文字输入框时触发。已核对游戏默认按键，自定义游戏键位可能冲突。其他工具按键只在绘图模式捕获输入时生效。按 E 返回游戏后才能正常移动镜头。

## 固定在格子上的路径

进入关卡，按 E → H，等待“自动格子”和“游戏主相机已连接”。通常需要几秒和足够的规则实例，不需要手动校准。

开启“格心预览”，确认吸附点与地面一致，再点击格心开始路径；点击同一行或同一列的格子，沿途格心会连接。转弯处先加一个点；不接受直接跨向斜格。点击“结束路径 / 新路径”后可画另一条路线。

按 E 返回游戏后，路径根据游戏相机重新投影。每条路径保存自己的世界格子基准，后续识别变化不会移动旧路径。右键/Ctrl+Z 撤销最近一次添加并结束当前路径，K 可擦除整条路线。

该工具只标记路线，不会检查障碍、自动寻路、移动人物或推箱子。普通画笔、图形和文字仍固定在屏幕坐标。不同关卡请使用不同草稿页；页面不会自动按关卡名称分配。特殊斜面、楼层、过渡镜头、环绕地图和游戏更新后的表现需要实际核对。

## 光标

普通模式为浅金晶刃指针，带深色边缘和星芒刻纹；绘图为镂空星芒准星，中心提示笔色；橡皮为镂空符文圆环。尖端或准星中心对应鼠标位置，较高分辨率下会适当放大。

## 保存、导出和卸载

草稿位于游戏目录 `SinkingStarSketch-data/drafts.txt`，上一版为 `.bak`；语言设置为同目录的 `settings.ini`。工具栏“导出 SVG”写入 `exports` 子目录，世界路径使用导出时可用的相机投影；没有有效相机时该路径不能导出。每页最多 2000 条笔迹、合计 120000 个点、60 步撤销；撤销历史不跨重启保存。

新版可读取旧草稿；v3.x 写出的新格式不能交给 v2.1 读取，降级时使用升级备份。

退出游戏后双击 **卸载Mod.cmd**，或把游戏 EXE 拖到该文件上。已验证的 Mod 文件会移入 `SinkingStarSketch-disabled-*` 备份，存档、草稿、语言偏好和导出文件均保留，可能留下空的字体目录。遇到未知或修改过的二进制/字体会停止。

手动安装时将 `game_files` 内的内容复制到游戏 EXE 同级目录，并保留 `SinkingStarSketch-assets` 子目录。已有图形代理或 ReShade 时先处理兼容性。手动停用可在退出游戏后移出本插件；只有确认 `dxgi.dll` 属于本次安装且没有被其他插件共用时，才一并移出它。

## 排错和第三方组件

没有工具栏时确认安装在实际运行的 EXE 旁，完全重启游戏后按 E。格子或相机一直等待时进入普通关卡稍候，不要假定任意网格就是实际地面。

升级后中文缺字时，原 `ReShade.ini` 会被保留：请在 ReShade 字体设置中选择 `SinkingStarSketch-assets/NotoSansCJKsc-Regular.otf`。日志为 `ReShade.log` 和 `SinkingStarSketch-data/status.txt`；公开提交前请检查其中的个人路径。
